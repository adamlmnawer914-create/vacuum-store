# SpaceSave - Premium Vacuum Storage Bags

Un site e-commerce moderne et élégant pour la vente de sacs de compression sous vide haute qualité avec pompe à main incluse. Conçu pour le marché marocain avec paiement à la livraison (COD).

## 🚀 Fonctionnalités

- **Design Premium & Responsive** : Optimisé pour tous les écrans (Desktop, Tablette, Mobile).
- **Page d'Accueil Interactive** :
  - Section Hero avec bouton animé doré "اشتري الآن — Shop Now" avec défilement fluide.
  - Avantages clés et présentation des bénéfices.
  - Section Offre Spéciale avec détails complets de la composition du pack et fiche technique.
  - Section Avant / Après avec appel à l'action.
- **Formulaire de Commande COD (Cash on Delivery)** :
  - Fenêtre modale de commande fluide avec sélection de quantité et calcul de total en direct.
- **Page Contact dédiée (`/contact`)** :
  - Numéro de téléphone direct : `+212 6 42 39 47 56`.
  - Formulaire de message et informations de service client.
- **Lien Ecom Boost Pro** :
  - Footer avec lien direct WhatsApp vers l'agence de développement.

## 🛠️ Technologies Utilisées

- **Framework** : [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Styling** : [Tailwind CSS](https://tailwindcss.com/)
- **Polices** : Google Fonts (Inter, Cairo)
- **Icônes** : SVG Icons intégrés (Lucide / Heroicons)
- **Déploiement** : GitHub & Vercel

## 💻 Démarrage Local

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.
